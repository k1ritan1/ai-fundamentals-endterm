SEC 1.2 Theoretical Foundation & Mathematical Formulation

An intelligent agent is formally defined as an entity that perceives its environment through sensors and acts upon that environment through actuators. The agent behavior is governed by an internal agent function, denoted mathematically as:

$$ f: \mathcal{P}^* \to \mathcal{A} $$
Equation 1.1: Agent Function Mapping Percept Sequences to Actions

Here, \(\mathcal{P}^*\) represents the history of all percept sequences accumulated by the system up to time \(t\), and \(\mathcal{A}\) denotes the set of executable physical actions. In physical robotics, the agent program implements this function on physical hardware architecture under finite compute, memory, and battery constraints.

PEAS Specification: Exterior Repair Crawler Alpha-1
  • Performance Measure: Minimize path traversal cost, seal all structural breaches before atmospheric depletion (penalty: -1000 for breach blowout), minimize electrical energy consumption per centimeter traveled, avoid hull fracture obstacles.
  • Environment: Microgravity exterior hull surface, localized decompression craters, radiation plumes, temperature differentials from -150°C to +120°C, high-frequency cosmic noise.
  • Actuators: Magnetic crawler tracks with dual brushless DC motors, cold-gas RCS stabilization thrusters, multi-axis robotic welding arm, inductive surface clamps.
  • Sensors: Stereoscopic LIDAR array (10 Hz point cloud), surface ultrasonic thickness transducer, 6-axis inertial measurement unit (IMU), battery shunt ammeter.

Understanding the mathematical nature of the operational environment dictates algorithm selection:

  • Observability: Partially observable if hull debris occludes remote sectors; fully observable once the orbital LIDAR satellite relays the elevation grid map.
  • Determinism: Stochastic in the presence of micro-meteoroid impacts and track slip, though modeled deterministically for initial path generation.
  • Episodic vs. Sequential: Sequential. Current steering decisions affect future crawler stability, power levels, and distance to the target breach.
  • Static vs. Dynamic: Dynamic. Breach expansion and debris trajectories alter traversability while the agent calculates its route.
  • Discrete vs. Continuous: Continuous physical motion, discretized into a navigation grid graph \(G = (V, E)\) for computational tractability.

Formally, a search problem on the hull grid is defined by a 5-tuple:

$$ \langle S_0, \text{Actions}(s), \text{Result}(s, a), \text{Goal-Test}(s), c(s, a, s') \rangle $$
Equation 1.2: Formal Problem Formulation Tuple

Where \(S_0\) is the initial coordinate state, \(\text{Actions}(s)\) returns the set of legal directional movements, \(\text{Result}(s, a)\) yields the deterministic transition state \(s'\), \(\text{Goal-Test}(s)\) verifies arrival at the target breach coordinate, and \(c(s, a, s')\) is the step cost representing energy consumption and surface traversal roughness.

In uninformed search, the agent explores states without domain-specific knowledge beyond the step cost. Breadth-First Search (BFS) expands the shallowest unexpanded node using a FIFO queue, guaranteeing optimality when all step costs are equal (\(c = 1\)). Depth-First Search (DFS) expands the deepest node via a LIFO stack, which requires minimal space \(O(bm)\) but risks non-termination in cyclic graphs and fails to guarantee shortest paths. Uniform-Cost Search (UCS), equivalent to Dijkstra algorithm, expands nodes in order of cumulative path cost \(g(n)\) via a priority queue:

$$ g(n) = \sum_{i=1}^{k} c(s_{i-1}, a_i, s_i) $$
Equation 1.3: Cumulative Path Cost from Start to Node n

UCS is complete and cost-optimal for positive edge costs \(c(s, a, s') \ge \epsilon > 0\), but it explores uniformly in all directions, expanding unnecessary nodes opposite the target goal.

Informed search introduces a heuristic function \(h(n)\), estimating the remaining cost to the goal from node \(n\). The \(A^*\) search algorithm combines the actual past cost \(g(n)\) with the estimated future cost \(h(n)\):

$$ f(n) = g(n) + h(n) $$
Equation 1.4: A* Node Evaluation Function

For grid navigation with orthogonal 4-way movement, the Manhattan distance heuristic is calculated as:

$$ h_{\text{Manhattan}}(n) = |x_n - x_g| + |y_n - y_g| $$
Equation 1.5: Manhattan Distance Heuristic

When diagonal movement is permitted, the Euclidean distance provides a straight-line geometric lower bound:

$$ h_{\text{Euclidean}}(n) = \sqrt{(x_n - x_g)^2 + (y_n - y_g)^2} $$
Equation 1.6: Euclidean Distance Heuristic

To guarantee that \(A^*\) finds the optimal path without suboptimal lock-in, the heuristic must satisfy two mathematical properties:

Mathematical Conditions for A* Optimality

1. Admissibility (Tree Search Optimality): A heuristic \(h(n)\) is admissible if it never overestimates the true minimal cost \(h^*(n)\) to reach the goal:

$$ \forall n, \quad 0 \le h(n) \le h^*(n) $$

Proof sketch: Suppose a suboptimal goal \(G_2\) is selected from the frontier before the optimal goal \(G\). Because \(G_2\) is a goal node, \(h(G_2) = 0\), so \(f(G_2) = g(G_2) > g(G)\). For any ancestor node \(n\) of \(G\) on the frontier, \(f(n) = g(n) + h(n) \le g(n) + h^*(n) = g(G) < g(G_2) = f(G_2)\). Hence, \(A^*\) will always expand \(n\) before \(G_2\), ensuring \(G_2\) cannot be returned first.

2. Consistency / Monotonicity (Graph Search Optimality): In graph search with a closed set (explored table), a heuristic \(h(n)\) is consistent if for every node \(n\) and every successor \(n'\) generated by action \(a\), the estimated cost satisfies the triangle inequality:

$$ h(n) \le c(n, a, n') + h(n') $$

Consistency guarantees that the sequence of \(f(n)\) values along any path is non-decreasing: \(f(n') = g(n') + h(n') = g(n) + c(n, a, n') + h(n') \ge g(n) + h(n) = f(n)\). Consequently, the first time \(A^*\) expands a state, the path found to that state is guaranteed to be optimal, eliminating the need to reopen nodes in the closed set.

Dominance: Given two admissible heuristics \(h_1\) and \(h_2\), if \(h_2(n) \ge h_1(n)\) for all nodes \(n\), then \(h_2\) dominates \(h_1\). A dominating heuristic expands fewer or equal nodes than \(h_1\), directly conserving embedded CPU cycles.

function A_STAR_HULL_SEARCH(grid, start, goal, heuristic_fn):
    // Priority queue holds tuples (f_cost, node_coords)
    frontier = PriorityQueue()
    frontier.insert(item=start, priority=heuristic_fn(start, goal))
    
    // Tracking tables
    came_from = HashMap()          // Maps node -> predecessor node
    cost_so_far = HashMap()        // Maps node -> g_cost
    closed_set = HashSet()         // Explored nodes
    
    cost_so_far[start] = 0
    came_from[start] = null
    
    while not frontier.is_empty():
        current = frontier.extract_min()
        
        // Goal test upon expansion, not generation
        if current == goal:
            return RECONSTRUCT_PATH(came_from, current)
            
        if current in closed_set:
            continue
        closed_set.add(current)
        
        for next_node in grid.get_passable_neighbors(current):
            if next_node in closed_set:
                continue
                
            new_cost = cost_so_far[current] + grid.traversal_cost(current, next_node)
            
            if next_node not in cost_so_far or new_cost < cost_so_far[next_node]:
                cost_so_far[next_node] = new_cost
                priority = new_cost + heuristic_fn(next_node, goal)
                frontier.insert(item=next_node, priority=priority)
                came_from[next_node] = current
                
    return FAILURE // No passable path through hull breach debris

SEC 2.2 Theoretical Foundation & Mathematical Formulation

When the sequence of actions leading to a goal is irrelevant and only the final configuration matters, the planning challenge transitions from pathfinding to local search and optimization. In local search, the algorithm maintains one or more active states and moves iteratively toward neighboring configurations on an objective function surface \(f(s)\).

Hill-Climbing search (greedy local search) continuously moves in the direction of increasing objective value \(\Delta f > 0\). In state-space landscapes with complex topologies, standard hill climbing suffers from three classic structural failure modes:

  • Local Maxima: Peaks higher than neighboring states but lower than the global optimum, trapping the greedy search.
  • Plateaus: Flat regions where neighboring states have identical evaluation scores (\(\Delta f = 0\)), causing the search to wander aimlessly without a directional gradient.
  • Ridges: Sequences of local maxima that slope gently upward, where individual orthogonal steps in any cardinal direction yield lower values, stalling progress.

To escape local traps, Simulated Annealing borrows principles from statistical thermodynamics, modeling the controlled cooling of metallurgical crystal structures. At each iteration, a random neighbor state \(s'\) is generated. If \(s'\) improves the objective (\(\Delta E = f(s) - f(s') < 0\) for cost minimization), the transition is accepted unconditionally. If the neighbor worsens the objective (\(\Delta E > 0\)), the algorithm accepts the move probabilistically according to the Boltzmann-Gibbs distribution:

$$ P(\text{accept } s' \mid s) = \begin{cases} 1 & \text{if } \Delta E \le 0 \\ \exp\left(-\frac{\Delta E}{T}\right) & \text{if } \Delta E > 0 \end{cases} $$
Equation 2.1: Metropolis-Hastings Acceptance Criterion

Here, \(T\) is an artificial temperature parameter governed by a monotonic annealing cooling schedule \(T(t)\), such as geometric decay \(T_{k+1} = \alpha T_k\) where \(0.85 \le \alpha < 1.0\). When \(T\) is high, the agent accepts suboptimal moves freely, exploring diverse energy basins. As \(T \to 0\), the probability of accepting worse moves approaches zero, causing the algorithm to settle smoothly into the nearest deep optimum.

Formal Constraint Satisfaction Problem (CSP) Definition

A Constraint Satisfaction Problem is formally defined as a 3-tuple \(\langle X, D, C \rangle\):

  • Variables \(X\): A finite set of variables \(X = \{X_1, X_2, \dots, X_n\}\). For the power grid: \(X = \{\text{LS}, \text{KS}, \text{CP}, \text{NV}, \text{TR}, \text{CM}\}\).
  • Domains \(D\): A set of discrete domains \(D = \{D_1, D_2, \dots, D_n\}\), where each \(D_i\) represents the allowable power levels for variable \(X_i\). For example, \(D_{\text{LS}} = \{2, 3\}\), \(D_{\text{TR}} = \{0, 1, 2, 3\}\).
  • Constraints \(C\): A set of constraints \(C = \{C_1, C_2, \dots, C_m\}\). Each constraint \(C_j = \langle \text{scope}, R \rangle\) specifies the subset of variables involved and the relation restricting their simultaneous assignments.

The Daedalus emergency power allocation is constrained by physical hardware limitations:

$$ \begin{aligned} &C_1: \quad \text{LS} + \text{KS} + \text{CP} + \text{NV} + \text{TR} + \text{CM} \le 8.0 \quad \text{(Total Bus Capacity Limit)} \\ &C_2: \quad \text{KS} + \text{TR} \le 4.0 \quad \text{(Substation Alpha Overheating Threshold)} \\ &C_3: \quad \text{LS} \ge 2.0 \quad \text{(Life Support Atmospheric Scrubbing Minimum)} \\ &C_4: \quad \text{CP} \ge 1.0 \quad \text{(Cryogenic Stasis Cryo-Fluid Recirculation)} \end{aligned} $$
Equation 2.2: Physical Hard Constraints on Vessel Electrical Buses

Solving CSPs through pure backtracking search (depth-first search with single-variable trial assignments) has a worst-case time complexity of \(O(d^n)\), where \(d = \max |D_i|\) is domain size and \(n\) is the number of variables. To achieve tractability, the agent combines search with constraint propagation.

Inference: Arc Consistency (AC-3) & Variable Ordering Heuristics

A directed arc \((X_i, X_j)\) in the constraint graph is arc-consistent if for every value \(x \in D_i\), there exists at least one value \(y \in D_j\) satisfying the constraint between \(X_i\) and \(X_j\). The AC-3 algorithm enforces pairwise consistency across all arcs:

$$ \forall x \in D_i, \quad \exists y \in D_j \quad \text{such that} \quad (x, y) \in R_{ij} $$

If no such \(y\) exists, \(x\) is pruned from \(D_i\). Whenever a domain is modified, all incoming arcs \((X_k, X_i)\) are re-added to the verification queue. The maximum time complexity of AC-3 is \(O(cd^3)\), where \(c\) is the number of binary constraints.

Backtracking efficiency is enhanced by three standard heuristics:

  • Minimum Remaining Values (MRV / "Fail-First"): Choose the unassigned variable with the fewest remaining legal values in its domain. This prunes failing branches at the shallowest possible depth.
  • Degree Heuristic: Used as a tie-breaker for MRV; selects the variable involved in the largest number of constraints with other unassigned variables.
  • Least Constraining Value (LCV / "Fail-Last"): Given a chosen variable, select the domain value that eliminates the fewest choices for neighboring variables in the constraint graph.

function SOLVE_POWER_GRID_CSP(variables, domains, constraints):
    // Enforce initial arc consistency before starting search
    if not AC3(variables, domains, constraints):
        return FAILURE // Inconsistent constraints: immediate bus trip
    return BACKTRACK(assignment={}, variables, domains, constraints)

function AC3(variables, domains, constraints):
    queue = Queue()
    for each binary constraint C(Xi, Xj) in constraints:
        queue.push((Xi, Xj))
        queue.push((Xj, Xi))
        
    while not queue.is_empty():
        (Xi, Xj) = queue.pop()
        if REVISE(Xi, Xj, domains, constraints):
            if len(domains[Xi]) == 0:
                return false // Domain wiped out, problem unsolvable
            for each Xk in NEIGHBORS(Xi) - {Xj}:
                queue.push((Xk, Xi))
    return true

function REVISE(Xi, Xj, domains, constraints):
    revised = false
    for each x in copy(domains[Xi]):
        // Check if there is any y in Dj satisfying constraint(x, y)
        if not any(constraints.satisfies(Xi=x, Xj=y) for y in domains[Xj]):
            domains[Xi].remove(x)
            revised = true
    return revised

function BACKTRACK(assignment, variables, domains, constraints):
    if len(assignment) == len(variables):
        return assignment // All power buses successfully scheduled
        
    // Apply MRV (Minimum Remaining Values) heuristic
    var = SELECT_UNASSIGNED_VARIABLE_MRV(assignment, variables, domains)
    
    // Apply LCV (Least Constraining Value) ordering
    for each value in ORDER_DOMAIN_VALUES_LCV(var, assignment, domains, constraints):
        if IS_CONSISTENT(var, value, assignment, constraints):
            assignment[var] = value
            
            // Forward checking: prune conflicting values from neighbor domains
            inferences = FORWARD_CHECK(var, value, assignment, domains, constraints)
            if inferences != FAILURE:
                result = BACKTRACK(assignment, variables, domains, constraints)
                if result != FAILURE:
                    return result
                    
            delete assignment[var]
            RESTORE_DOMAINS(inferences, domains)
            
    return FAILURE

SEC 3.2 Theoretical Foundation & Mathematical Formulation

In single-agent search (such as \\(A^*\\)), the environment is passive: the agent plans a trajectory through a static or stochastic world that does not actively attempt to frustrate its objectives. In adversarial environments, multiple agents possess conflicting utility functions.

Formal Zero-Sum Game Definition

A two-player, perfect-information, turn-taking zero-sum game is defined by a 6-tuple:

$$ \\langle S_0, \\text{Player}(s), \\text{Actions}(s), \\text{Result}(s, a), \\text{Terminal-Test}(s), \\text{Utility}(s, p) \\rangle $$
  • Initial State \\(S_0\\): The starting physical layout of sentry turrets and intruder drones in Cargo Bay 3.
  • Player Function \\(\\text{Player}(s)\\): Defines whose turn it is to act (\\(\\text{MAX}\\) representing ship sentry defense; \\(\\text{MIN}\\) representing the hostile scavenger).
  • Actions \\(\\text{Actions}(s)\\): The set of legal maneuvers or firing solutions available to the active player in state \\(s\\).
  • Transition Model \\(\\text{Result}(s, a)\\): Returns the resulting state after executing action \\(a\\).
  • Terminal Test \\(\\text{Terminal-Test}(s)\\): True if the engagement is resolved (e.g., intruder destroyed or cryogenic line severed); false otherwise.
  • Utility Function \\(\\text{Utility}(s, p)\\): A numeric payoff function for player \\(p\\) at terminal state \\(s\\). In zero-sum games: \\(\\text{Utility}_{\\text{MAX}}(s) + \\text{Utility}_{\\text{MIN}}(s) = 0\\).

The Minimax algorithm computes the optimal strategy for \\(\\text{MAX}\\) under the fundamental assumption that \\(\\text{MIN}\\) plays with perfect rationality to minimize \\(\\text{MAX}\\) payoff. The recursive minimax value \\(V(s)\\) is expressed as:

$$ V(s) = \\begin{cases} \\text{Utility}(s) & \\text{if } \\text{Terminal-Test}(s) \\\\ \\max_{a \\in \\text{Actions}(s)} V(\\text{Result}(s, a)) & \\text{if } \\text{Player}(s) = \\text{MAX} \\\\ \\min_{a \\in \\text{Actions}(s)} V(\\text{Result}(s, a)) & \\text{if } \\text{Player}(s) = \\text{MIN} \\end{cases} $$
Equation 3.1: The Minimax Value Function

A full minimax traversal over a game tree with branching factor \\(b\\) and maximum depth \\(m\\) requires \\(O(b^m)\\) time and \\(O(bm)\\) memory. In physical combat with a 40-millisecond cycle deadline, searching to terminal depth is impossible. The engine must truncate search at a fixed cutoff depth \\(d\\) and apply a linear weighted evaluation function \\(V_{\\text{eval}}(s) = f(\\mathbf{w})\\):

$$ V_{\\text{eval}}(s) = f(\\mathbf{w}) = \\mathbf{w}^T \\mathbf{f}(s) = \\sum_{i=1}^{k} w_i f_i(s) = w_1 (\\text{Intruder Distance}) + w_2 (\\text{Turret Line-of-Sight}) + w_3 (\\text{Ammunition Reserve}) $$
Equation 3.2: Linear Weighted Evaluation Function for Real-Time Cutoff
Mathematical Formulation of Alpha-Beta Pruning

Alpha-Beta pruning computes the exact minimax decision while pruning subtrees that cannot influence the final root value. The algorithm tracks two parameters along the search path:

  • \\(\\alpha\\): The value of the best (highest-value) choice found so far along the path for \\(\\text{MAX}\\). Initialized to \\(-\\infty\\).
  • \\(\\beta\\): The value of the best (lowest-value) choice found so far along the path for \\(\\text{MIN}\\). Initialized to \\(+\\infty\\).

Pruning Condition: At any point during tree traversal, whenever:

$$ \\alpha \\ge \\beta $$

the remaining child branches of the current node are pruned immediately.

Proof: Consider a \\(\\text{MIN}\\) node \\(n\\) where \\(v \\le \\alpha\\). The parent \\(\\text{MAX}\\) ancestor already has an alternative path guaranteeing a payoff of at least \\(\\alpha\\). Because \\(n\\) is controlled by \\(\\text{MIN}\\), its value can only decrease further as remaining children are evaluated. Therefore, \\(\\text{MAX}\\) will never choose the branch leading to \\(n\\). Exploring further children of \\(n\\) cannot alter the decision at the parent, proving the pruning is strictly conservative and sound.

Pruning Efficiency: With arbitrary move ordering, alpha-beta examines \\(O(b^{3m/4})\\) nodes. Under perfect move ordering (where the best move is always evaluated first), time complexity drops to:

$$ O(b^{m/2}) $$

This doubles the effective search depth achievable within the same compute time budget.

When the environment includes stochastic elements (such as debris deflection, turret jamming, or venting atmospheric gas), the Expectimax algorithm replaces deterministic \\(\\text{MIN}\\) nodes with chance nodes:

$$ V_{\\text{Expectimax}}(s) = \\sum_{s'} P(s' \\mid s, a) V_{\\text{Expectimax}}(s') $$
Equation 3.3: Expectimax Formulation over Chance Nodes

Unlike Minimax, which is invariant to positive monotonic transformations of the evaluation function, Expectimax values depend strictly on positive affine transformations: \\(U'(s) = c_1 U(s) + c_2\\) where \\(c_1 > 0\\). Non-linear scaling distorts expected values, altering the resulting physical actions.

SEC 4.2 Theoretical Foundation & Mathematical Formulation

When an agent acts in a stochastic environment where actions have uncertain outcomes and consequences play out over extended time horizons, decision-making is formalized through the mathematical framework of Markov Decision Processes.

Formal Markov Decision Process (MDP) Definition

A discounted Markov Decision Process is defined as a 5-tuple \(\langle S, A, T, R, \gamma \rangle\):

  • State Space \(S\): The set of all valid environmental states. For the tokamak reactor: discretized temperature-pressure vectors across grid sectors.
  • Action Space \(A\): The set of executable control actions, \(A = \{\text{Inject Vent}, \text{Increase Flow}, \text{Decrease Flow}, \text{Bypass Loop}\}\).
  • Transition Model \(T(s, a, s') = P(s' \mid s, a)\): The conditional probability that executing action \(a\) in state \(s\) leads to state \(s'\). Satisfies \(\sum_{s' \in S} T(s, a, s') = 1\).
  • Reward Function \(R(s, a, s')\): The real-valued scalar feedback received upon transitioning. Stable thermal baseline yields \(+10\); plasma containment breach yields \(-100\); step energy cost is \(-0.1\).
  • Discount Factor \(\gamma \in [0, 1)\): Models the preference for immediate rewards over deferred rewards, ensuring mathematical convergence over infinite horizons:
$$ G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} $$
Equation 4.1: Discounted Cumulative Return from Time t

The foundational assumption enabling tractable dynamic programming is the Markov Property: future states depend solely on the current state and action, independent of the historical percept trajectory:

$$ P(S_{t+1} = s' \mid S_t = s_t, A_t = a_t, S_{t-1} = s_{t-1}, \dots, S_0 = s_0) = P(S_{t+1} = s' \mid S_t = s_t, A_t = a_t) $$
Equation 4.2: The First-Order Markov Property

An agent behavior is specified by a policy \(\pi(a \mid s)\). The state-value function \(V^\pi(s)\) quantifies expected return from state \(s\) under policy \(\pi\), while the action-value function \(Q^\pi(s, a)\) quantifies the expected return of taking action \(a\) in state \(s\) before following \(\pi\).

Bellman Expectation & Optimality Equations

The Bellman Expectation Equation decomposes the value of a state recursively into immediate reward plus discounted expected future value:

$$ V^\pi(s) = \sum_{a \in A} \pi(a \mid s) \sum_{s' \in S} T(s, a, s') \left[ R(s, a, s') + \gamma V^\pi(s') \right] $$

The optimal policy \(\pi^*\) achieves the maximal value function across all states: \(V^*(s) = \max_\pi V^\pi(s)\). The Bellman Optimality Equations express the non-linear relationship that must hold at equilibrium:

$$ V^*(s) = \max_{a \in A} \sum_{s' \in S} T(s, a, s') \left[ R(s, a, s') + \gamma V^*(s') \right] $$
$$ Q^*(s, a) = \sum_{s' \in S} T(s, a, s') \left[ R(s, a, s') + \gamma \max_{a' \in A} Q^*(s', a') \right] $$

Once \(Q^*(s, a)\) is known, the optimal deterministic policy is extracted greedily: \(\pi^*(s) = \arg\max_a Q^*(s, a)\).

When the environmental transition dynamics \(T\) and reward function \(R\) are known, Value Iteration solves for \(V^*\) through fixed-point iteration:

$$ V_{k+1}(s) \leftarrow \max_{a \in A} \sum_{s' \in S} T(s, a, s') \left[ R(s, a, s') + \gamma V_k(s') \right] $$
Equation 4.3: Value Iteration Update Rule

By the Banach Fixed-Point Theorem, the Bellman backup operator is a \(\gamma\)-contraction mapping in the \(L_\infty\) norm: \(\|\mathcal{T}V - \mathcal{T}U\|_\infty \le \gamma \|V - U\|_\infty\). Because \(\gamma < 1\), value iteration converges to a unique fixed point regardless of initialization:

$$ \|V_{k+1} - V^*\|_\infty \le \frac{2\gamma}{1 - \gamma} \|V_k - V_{k-1}\|_\infty $$
Equation 4.4: Contraction Mapping Error Bound
Model-Free Reinforcement Learning: Temporal Difference Q-Learning

When plasma dynamics are too turbulent to model explicitly, the transition probabilities \(T(s, a, s')\) are unknown. The agent must learn directly from experiential transitions \((s_t, a_t, r_{t+1}, s_{t+1})\).

Watkins Q-Learning is an off-policy Temporal Difference control algorithm. It updates the state-action value table by comparing the current estimate to a bootstrap target:

$$ Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t) \right] $$

Where:

  • \(\alpha \in (0, 1]\) is the learning rate parameter.
  • \(\delta_t = R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t)\) is the Temporal Difference (TD) error.
  • \(R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a')\) is the target value.

Exploration vs. Exploitation: To discover high-reward states while refining known policies, the agent uses an \(\epsilon\)-greedy behavioral policy: with probability \(1 - \epsilon\), it selects \(\arg\max_a Q(s, a)\); with probability \(\epsilon\), it selects a random exploratory action.

Classical propositional and first-order logic fail in physical robotics due to the qualification problem: the exhaustive list of antecedents required to guarantee an outcome is intractable to formalize. Physical environments are governed by uncertainty arising from partial observability, noisy sensors, non-deterministic actuators, and computational limits.

Axioms of Probability & Bayes' Rule

Probability theory formalizes degrees of belief over propositions. The Kolmogorov axioms establish the mathematical foundation:

  1. \(\forall A, \quad 0 \le P(A) \le 1\)
  2. \(P(\Omega) = 1\), where \(\Omega\) is the sample space.
  3. For mutually exclusive events \(A\) and \(B\): \(P(A \cup B) = P(A) + P(B)\).

Conditional probability is defined as \(P(A \mid B) = \frac{P(A \cap B)}{P(B)}\) for \(P(B) > 0\). The Product Rule yields the Joint Probability Distribution: \(P(A, B) = P(A \mid B) P(B) = P(B \mid A) P(A)\). Equating these expressions yields Bayes' Rule:

$$ P(\text{Cause} \mid \text{Effect}) = \frac{P(\text{Effect} \mid \text{Cause}) P(\text{Cause})}{P(\text{Effect})} $$
Equation 5.1: Bayes' Rule for Diagnostic Inference

Using the Law of Total Probability to expand the marginal denominator \(P(E) = \sum_c P(E \mid C = c) P(C = c)\), Bayes' Rule in normalized form is written as:

$$ P(C \mid E) = \alpha P(E \mid C) P(C) $$
Equation 5.2: Normalized Posterior Probability Formulation

Where \(\alpha = 1 / \sum_c P(E \mid c) P(c)\) is a normalization constant ensuring the posterior distribution sums to 1.

Two variables \(X\) and \(Y\) are conditionally independent given \(Z\) if:

$$ P(X, Y \mid Z) = P(X \mid Z) P(Y \mid Z) \iff P(X \mid Y, Z) = P(X \mid Z) $$
Equation 5.3: Conditional Independence Relation

A Bayesian Network is a Directed Acyclic Graph (DAG) whose nodes represent random variables and whose directed edges represent direct probabilistic dependencies. Each node \(X_i\) is equipped with a Conditional Probability Table (CPT) specifying \(P(X_i \mid \text{Parents}(X_i))\). By exploiting conditional independence, the joint distribution factors into:

$$ P(X_1, X_2, \dots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Parents}(X_i)) $$
Equation 5.4: Joint Distribution Factorization over Bayesian Networks

Conditional independence is verified topologically through d-separation (directional separation). An undirected path between \(X\) and \(Y\) is blocked by evidence set \(E\) if the path contains:

  • A linear chain \(A \to B \to C\) or common cause \(A \leftarrow B \to C\), and \(B \in E\).
  • A collider / v-structure \(A \to B \leftarrow C\), and neither \(B\) nor any descendant of \(B\) is in \(E\). Observing a collider unblocks the path ("explaining away").
Hidden Markov Models (HMMs) & The Forward Filtering Algorithm

When physical variables evolve over time, we model the system as a Hidden Markov Model. Let \(X_t\) denote the unobservable true physical state at time step \(t\) (e.g., fracture in sector \(i \in \{1, \dots, 6\}\)), and \(E_t\) denote the noisy sensor observation at time \(t\).

The model satisfies two core independence assumptions:

  • First-Order Markov State Transition: \(P(X_t \mid X_{0:t-1}) = P(X_t \mid X_{t-1})\).
  • Sensor Markov Assumption: \(P(E_t \mid X_{0:t}, E_{1:t-1}) = P(E_t \mid X_t)\).

The primary task in real-time tracking is Filtering: computing the current belief state distribution \(P(X_t \mid e_{1:t})\) given the historical observation sequence \(e_{1:t} = (e_1, e_2, \dots, e_t)\).

Mathematical Derivation:

$$ \begin{aligned} P(X_t \mid e_{1:t}) &= P(X_t \mid e_t, e_{1:t-1}) \\ &= \alpha P(e_t \mid X_t, e_{1:t-1}) P(X_t \mid e_{1:t-1}) \quad \text{(by Bayes' Rule)} \\ &= \alpha P(e_t \mid X_t) P(X_t \mid e_{1:t-1}) \quad \text{(by Sensor Markov Assumption)} \end{aligned} $$

Expanding the one-step prediction term \(P(X_t \mid e_{1:t-1})\) by conditioning and marginalizing over the previous state \(x_{t-1}\):

$$ P(X_t \mid e_{1:t-1}) = \sum_{x_{t-1}} P(X_t \mid x_{t-1}, e_{1:t-1}) P(x_{t-1} \mid e_{1:t-1}) = \sum_{x_{t-1}} P(X_t \mid x_{t-1}) P(x_{t-1} \mid e_{1:t-1}) $$

Substituting yields the canonical recursive Forward Filtering Equation:

$$ P(X_t \mid e_{1:t}) = \alpha P(e_t \mid X_t) \sum_{x_{t-1}} P(X_t \mid x_{t-1}) P(x_{t-1} \mid e_{1:t-1}) $$
Equation 5.5: Recursive Forward Filtering Algorithm

SEC 6.2 Theoretical Foundation & Mathematical Formulation

Rational agents make decisions in uncertain environments by combining probabilistic beliefs with subjective preferences over states, formalized through Utility Theory.

Von Neumann-Morgenstern Utility Axioms & The MEU Principle

Let a lottery \(L = [p_1, S_1; p_2, S_2; \dots; p_n, S_n]\) represent a probabilistic distribution over outcomes \(S_i\) with probabilities \(p_i\) such that \(\sum p_i = 1\). Any rational preference relation \(\succ\) satisfies the six von Neumann-Morgenstern axioms:

  1. Orderability: Exactly one of \(A \succ B\), \(B \succ A\), or \(A \sim B\) holds.
  2. Transitivity: If \(A \succ B\) and \(B \succ C\), then \(A \succ C\).
  3. Continuity: If \(A \succ B \succ C\), then \(\exists p \in [0, 1]\) such that \([p, A; (1-p), C] \sim B\).
  4. Substitutability: If \(A \sim B\), then for all \(C\) and \(p\), \([p, A; (1-p), C] \sim [p, B; (1-p), C]\).
  5. Monotonicity: If \(A \succ B\), then \(p > q \iff [p, A; (1-p), B] \succ [q, A; (1-q), B]\).
  6. Decomposability: Compound lotteries can be reduced to equivalent simple lotteries via probability calculus.

When these axioms hold, there exists a real-valued utility function \(U(s)\) such that preferences are represented by expected utility. The Principle of Maximum Expected Utility (MEU) dictates that a rational agent chooses the action \(a^*\) maximizing expected utility:

$$ a^* = \arg\max_{a \in A} \sum_{s'} P(s' \mid s, a) U(s') $$
Equation 6.1: Principle of Maximum Expected Utility

The curvature of \(U(s)\) reflects operational risk posture:

  • Risk-Averse: Concave utility function (\(U''(w) < 0\)); \(\mathbb{E}[U(w)] < U(\mathbb{E}[w])\). The agent strictly prefers a guaranteed outcome over an uncertain lottery with equal expectation. Mandatory in life-support engineering.
  • Risk-Neutral: Linear utility function (\(U''(w) = 0\)); decisions depend solely on expected monetary or physical value.
  • Risk-Seeking: Convex utility function (\(U''(w) > 0\)); prefers the variance of lotteries.
Supervised Machine Learning & The Naive Bayes Classifier

In supervised classification, the agent is given a training dataset \(\mathcal{D} = \{(\mathbf{x}_1, y_1), \dots, (\mathbf{x}_m, y_m)\}\), where \(\mathbf{x}_i \in \mathbb{R}^d\) is a feature vector of sensor telemetry and \(y_i \in \{0, 1\}\) is the binary ground-truth label (0 = Nominal Cabin, 1 = Decompression Breach).

The Naive Bayes Classifier computes the posterior probability of class \(y\) using Bayes' rule, underpinned by the simplifying assumption that all feature dimensions \(x_1, x_2, \dots, x_d\) are conditionally independent given the class label \(y\):

$$ P(Y = c \mid x_1, x_2, \dots, x_d) = \frac{P(Y = c) \prod_{i=1}^{d} P(X_i = x_i \mid Y = c)}{P(x_1, x_2, \dots, x_d)} $$
Equation 6.2: Naive Bayes Posterior Probability Formulation

To prevent zero-frequency probability collapse when a novel sensor value is observed, we apply Laplace Smoothing (additive smoothing with pseudocount \(k = 1\)):

$$ P(X_i = v \mid Y = c) = \frac{\text{count}(X_i = v, Y = c) + 1}{\text{count}(Y = c) + |V_i|} $$
Equation 6.3: Laplace Smoothing Parameter Estimation

For continuous features, linear classifiers compute a score function \(z = \mathbf{w}^T \mathbf{x} + b\) and map it to a probability using the logistic sigmoid function:

$$ \sigma(z) = \frac{1}{1 + e^{-z}} = \frac{1}{1 + \exp(-(\mathbf{w}^T \mathbf{x} + b))} $$
Equation 6.4: Logistic Sigmoid Activation Function
Diagnostic Metrics & Cost-Sensitive Asymmetry

A binary classification model produces four distinct categorical outcomes:

  • True Positive (TP): Active breach correctly classified as breach (emergency bulkheads isolated).
  • False Positive (FP): Nominal cabin misclassified as breach (unnecessary lockdown; nitrogen loss).
  • True Negative (TN): Nominal cabin correctly classified as nominal.
  • False Negative (FN): Active breach misclassified as nominal (undetected decompression; crew hypoxia).

Standard performance metrics are defined as:

$$ \begin{aligned} \text{Precision} &= \frac{\text{TP}}{\text{TP} + \text{FP}} \quad \text{(Positive Predictive Value)} \\ \text{Recall (Sensitivity)} &= \frac{\text{TP}}{\text{TP} + \text{FN}} \quad \text{(True Positive Rate)} \\ F_1\text{-Score} &= 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\text{TP}}{2\text{TP} + \text{FP} + \text{FN}} \end{aligned} $$
Equation 6.5: Diagnostic Performance Metric Equations

Cost-Sensitive Decision Threshold: In life-critical space systems, accuracy is a misleading metric due to severe class imbalance. We formalize classification decisions through a cost matrix \(C(\hat{y}, y)\). The expected risk of predicting class 1 given posterior probability \(p = P(Y = 1 \mid \mathbf{x})\) is:

$$ \mathcal{R}(\text{predict } 1) = p \cdot C(1, 1) + (1 - p) \cdot C(1, 0) = (1 - p) \cdot \text{Cost}_{\text{False Positive}} $$
$$ \mathcal{R}(\text{predict } 0) = p \cdot C(0, 1) + (1 - p) \cdot C(0, 0) = p \cdot \text{Cost}_{\text{False Negative}} $$

Under this decision framework, the net expected value of taking action is \(\mathcal{V}(\text{Predict } 1) = -\mathcal{R}(\text{predict } 1)\). Predicting breach (\(\hat{y} = 1\)) is optimal if and only if \(\mathcal{R}(\text{predict } 1) < \mathcal{R}(\text{predict } 0)\). Solving for the critical decision threshold \(\tau^*\) yields:

$$ \tau^* = \frac{\text{Cost}_{\text{False Positive}} - \text{Cost}_{\text{True Negative}}}{[\text{Cost}_{\text{False Positive}} - \text{Cost}_{\text{True Negative}}] + [\text{Cost}_{\text{False Negative}} - \text{Cost}_{\text{True Positive}}]} = \frac{\text{Cost}_{\text{False Positive}}}{\text{Cost}_{\text{False Positive}} + \text{Cost}_{\text{False Negative}}} $$
Equation 6.6: Optimal Cost-Sensitive Bayesian Decision Threshold

Setting \(\text{Cost}_{\text{False Negative}} = 100\) (fatal hypoxia penalty) and \(\text{Cost}_{\text{False Positive}} = 1\) (false alarm cost) shifts the optimal operational threshold to \(\tau^* \approx 0.0099\). The system must favor high recall over precision to preserve crew life.

SEC 7.2 Theoretical Foundation & Mathematical Formulation

Biologically inspired computing models the parallel processing architecture of biological nervous systems, where computation arises from interconnected networks of simple processing nodes.

The Artificial Neuron: McCulloch-Pitts & Rosenblatt's Perceptron

The McCulloch-Pitts model (1943) abstracted biological neurons into binary threshold logic units. Frank Rosenblatt (1958) extended this architecture to create the Perceptron, an algorithm capable of learning continuous synaptic weights from empirical data:

$$ y = f(\mathbf{w}^T \mathbf{x} + b) = f\left( \sum_{i=1}^{d} w_i x_i + b \right) $$
Equation 7.1: Single-Layer Perceptron Output Function

Where \(\mathbf{x} = [x_1, \dots, x_d]^T\) is the input vector, \(\mathbf{w} = [w_1, \dots, w_d]^T\) is the learnable weight vector, \(b\) is the scalar bias, and \(f\) is an activation function (originally the Heaviside step function: \(f(z) = 1\) if \(z \ge 0\), else \(0\)).

The Perceptron Learning Rule updates weights iteratively on misclassified examples:

$$ w_i \leftarrow w_i + \eta (y - \hat{y}) x_i $$
Equation 7.2: Rosenblatt Perceptron Weight Update Rule

Where \(\eta \in (0, 1]\) is the learning rate. The Perceptron Convergence Theorem guarantees that if training data is linearly separable, the algorithm finds a separating hyperplane in finite steps.

The Linear Separability Barrier (The XOR Problem): As proven by Minsky and Papert (1969), a single-layer perceptron can only compute linearly separable boolean functions (AND, OR). It cannot compute non-linear functions such as Exclusive-OR (XOR), halting connectionist AI research for over a decade.

Multi-Layer Perceptrons (MLPs) & Backpropagation Calculus

Overcoming linear limitations requires multi-layer feedforward networks with non-linear activation functions. By the Universal Approximation Theorem (Cybenko 1989; Hornik 1991), a feedforward network with a single hidden layer containing finite non-linear neurons can approximate any continuous function on compact subsets of \(\mathbb{R}^d\) to arbitrary precision.

Modern networks replace non-differentiable step functions with continuous activations:

  • Logistic Sigmoid: \(\sigma(z) = \frac{1}{1 + e^{-z}}\); derivative \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\).
  • Hyperbolic Tangent: \(\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}\); zero-centered, \(\tanh'(z) = 1 - \tanh^2(z)\).
  • Rectified Linear Unit (ReLU): \(f(z) = \max(0, z)\); solves vanishing gradients for positive inputs; derivative \(f'(z) = 1\) for \(z > 0\).

Training deep networks requires computing the gradient of a scalar loss function \(\mathcal{L}\) with respect to every weight parameter. The Backpropagation Algorithm applies the multivariable calculus chain rule, propagating error terms backward from output to input:

$$ \frac{\partial \mathcal{L}}{\partial w_{ij}^{(l)}} = \frac{\partial \mathcal{L}}{\partial z_j^{(l)}} \frac{\partial z_j^{(l)}}{\partial w_{ij}^{(l)}} = \delta_j^{(l)} a_i^{(l-1)} $$
Equation 7.3: Weight Gradient Decomposition via Chain Rule

Where \(a_i^{(l-1)}\) is the activation of neuron \(i\) in layer \(l-1\), \(z_j^{(l)} = \sum_i w_{ij}^{(l)} a_i^{(l-1)} + b_j^{(l)}\), and the local error gradient \(\delta_j^{(l)}\) is computed recursively:

$$ \delta_j^{(l)} = \left( \sum_{k} \delta_k^{(l+1)} w_{jk}^{(l+1)} \right) \cdot f'\left(z_j^{(l)}\right) $$
Equation 7.4: Recursive Error Backpropagation Across Layers
Transformers, Scaled Dot-Product Attention, & AI Safety Alignment

Sequential recurrent networks (RNNs/LSTMs) suffer from computational bottlenecks due to sequential dependency across time steps \(t\). The Transformer Architecture (Vaswani et al. 2017) eliminates recurrence entirely, relying on the Self-Attention mechanism to model pairwise dependencies across all tokens simultaneously in \(O(1)\) sequential operations.

Input representations \(\mathbf{X} \in \mathbb{R}^{n \times d}\) are projected into Queries \(\mathbf{Q}\), Keys \(\mathbf{K}\), and Values \(\mathbf{V}\) via learnable projection matrices \(\mathbf{W}^Q, \mathbf{W}^K, \mathbf{W}^V \in \mathbb{R}^{d \times d_k}\). The Scaled Dot-Product Attention is defined as:

$$ \text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left( \frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}} \right) \mathbf{V} $$
Equation 7.5: Scaled Dot-Product Self-Attention

The scaling factor \(\frac{1}{\sqrt{d_k}}\) prevents the dot products from growing excessively large in high dimensions, which would push the softmax function into regions with vanishingly small gradients.
